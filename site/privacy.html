RelayroomPrivacy notice

A single connection check.

Relayroom is a static connection-preparation tool. It has no application server, analytics or advertising.

  • The public Client ID, a random request state and a timestamp are saved in this tab’s session storage when you start a check. They are removed when the callback is processed. Closing the tab also clears that storage.
  • If you authorize access, the callback reads the returned access token in browser memory and removes the URL fragment. It sends that token only to Twitch’s token-validation endpoint.
  • The validation response includes an account ID, login, client ID, permissions and expiry. Relayroom checks the app, account, permission and expiry fields, then discards the response and token. It does not display or store your account identity.
  • Relayroom does not read chat messages, send messages, start broadcasts or maintain an OAuth session. The requested read-only chat permission is checked for the planned connection probe.
  • GitHub Pages serves the files and may process request metadata such as IP addresses under GitHub’s privacy statement. Twitch processes authorization and validation under Twitch’s privacy notice.
  • Closing this page ends the local check; it does not revoke the permission you granted on Twitch. You can remove that permission in Twitch’s Connections settings.

This notice describes this version of the connection tool, dated October 30, 2026.
