RelayroomConnection check

Check your Twitch connection.

Set up a callback, then check that Twitch can return authorization to this app. Chat and streaming are not tested here.

1. Register the callback

In your own Twitch application, add the URL below as an OAuth Redirect URL. Use a Confidential client for this implicit-grant flow. A client secret is not used by this browser check.

Copy the complete URL, including the trailing slash.

App registration, any account verification and developer terms are completed by the account owner in Twitch.

2. Start a connection check

Use the public Client ID from that same application. Twitch will ask you to review read-only chat access.

Do not enter a client secret, password or access token.

This is a connection-preparation tool, not a working stream experience or a contest submission.
